# Rajbanshi Global News Network (RGNN) - Deployment & Hosting Guide

## 1. Hosting Architecture
- **Frontend/Backend**: Currently running on Google Cloud Run via this AI Studio container.
- **Production Recommendation**: Deploy to **Google Cloud Run** or **Vercel** with a Node.js runtime for the Express server.
- **Database**: **Firebase Firestore**. Use the Provisioning tool in AI Studio to connect your personal Firebase project.

## 2. API Configurations
- **Gemini AI**: Ensure `GEMINI_API_KEY` is set in your environment variables.
- **Firebase**: Once you connect your Firebase project, update `firebase-applet-config.json` (auto-generated by the setup tool).

## 3. SEO Optimization
- The platform uses Semantic HTML (H1, H2, Article tags).
- **MetaData**: Managed in `metadata.json` and React Header components.
- **PWA**: Add a `manifest.json` and a Service Worker for offline support and "Install App" functionality on mobile.

## 4. Mobile App (PWA)
- The website is **Mobile-First**. On mobile devices, users can "Add to Home Screen" to install it as an app.
- Includes touch-optimized swipe gestures (to be extended in further iterations).
- Push Notifications: Integrated via Firebase Cloud Messaging.

## 5. Deployment Commands
```bash
npm run build   # Build production assets
npm start       # Start production server
```

## 6. Monetization
- **AdSense**: Place your publisher ID in the Advertisement sections within `Sidebar.tsx` and `Home.tsx`.
- **Subscriptions**: Can be integrated using Stripe via the Express server.
